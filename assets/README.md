# Assets

Store approved project artwork and media here. Keep editable/master files separate from optimized runtime exports where practical.

- 00-reference-library: screenshots, inspiration, source HTML and reference notes.
- 01-environments: world scenes, backgrounds and parallax layers.
- 02-characters-companions: character concepts, sprites, expressions and animations.
- 03-objects-collectibles: props, decorations and interactive objects.
- 04-ui-artwork: app icons, badges and custom interface illustrations.
- 05-audio: original sound effects and ambient audio, if approved.
- 06-exported-sprite-sheets: runtime sprite sheets and animation exports.
- 07-fonts-licenses: font files and license/source information.

Record provenance and license. Do not commit unlicensed copyrighted reference material as project-owned art. Use Git LFS or an external asset store if large binaries exceed practical Git limits.
