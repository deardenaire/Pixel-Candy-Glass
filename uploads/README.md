# Uploads — Your File Inbox

If unsure where a file belongs, upload it to 02-future-material. Existing documents go in 00-existing-documents; existing HTML/source/prototypes go in 01-existing-project-files; items needing clarification go in 03-review-needed.

Use GitHub Add file → Upload files. Keep original filenames where practical, add a clear commit message and tell the project team what the file is. Do not silently overwrite approved baselines. Do not upload secrets, passwords, private keys or unrelated private records.
