# 03.4 — Release & Deployment Specification

**Status:** Pending architecture audit and target decision.

Define target platforms/minimum devices; local development/test environments; build configuration; environment variables/secrets; database migrations/backups; asset bundling/caching/versioning; installability/PWA if applicable; versioning/release notes; monitoring/error reporting; performance/accessibility gates; privacy disclosures; data export/deletion; rollback/recovery.

No release until critical acceptance criteria pass, high-severity defects are resolved or explicitly accepted, approved existing features pass regression, backup/restore is tested, secrets are absent, production configuration is reviewed and owner approves. Do not choose hosting before audit and owner decision.
