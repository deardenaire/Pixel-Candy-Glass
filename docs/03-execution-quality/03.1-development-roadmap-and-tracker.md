## Task record fields
Unique issue ID; workstream/app; spec reference; objective/scope; dependencies; priority; status; implementation status; verification status; actual start/completion dates; acceptance criteria; evidence; known issues; next action.

Issue status: Backlog / Ready / In Progress / Blocked / Review / Done / Deferred. Implementation: Not started / In progress / Implemented. Verification: Not tested / Passing / Failing / N/A. Done means implemented and verified, except documentation-only tasks. AI self-report is not evidence.
