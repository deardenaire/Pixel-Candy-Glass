# 00.1 — Master Project Brief

**Status:** Starter summary; reconcile with the owner's uploaded original.

## Product definition
Pixel Candy Glass is a mobile-first personal productivity experience combining a carefully art-directed Candy Glass operating interface, a persistent pixel-art world, and connected productivity applications. It must be genuinely useful and visually exceptional; neither quality compensates for the absence of the other.

## Two layers
**Mobile operating shell:** phone-like lock screen, date/time, PIN/unlock experience, home screen, app icons, app launching, navigation, transitions and shared settings. This is an app experience, not a replacement for the device operating system.

**Gamified world and productivity applications:** pixel-art environments, companions, props, collectibles and progress feedback, with real productivity tools remaining accessible and dependable.

## Product principles
1. Preserve and audit existing Mochi functionality before replacing anything.
2. Prefer incremental evolution over unnecessary rewrites.
3. Make every visible control functional.
4. Keep information architecture clear despite a rich visual world.
5. Persist data and progression reliably.
6. Organize reusable assets with provenance and versioning.
7. Design and validate mobile touch behavior first.
8. Treat performance, accessibility, privacy and recovery as core quality.
9. Mark assumptions and open decisions; do not invent product rules.

## Project lineage
The project grows from earlier Mochi Calendar / Mochi Workspace work. Existing source, documents, interactions, data and assets may contain important capabilities. Inventory and test them before proposing architecture or feature replacement. The current codebase and feature inventory have not yet been audited in this repository.
